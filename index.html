The key idea

Calligraphr = your mark library

Calligraphr turns any black mark into a character you can type.

  • Press A → your diagonal slash
  • Press B → your ink splatter

One mark for each job: 1–2 arrows · 1–2 dividers · 1 frame · 2–3 textures · 1 emphasis · 1 connector

  • Log in to calligraphr.com ↗ (your Week 1 account)
  • Click Templates → punctuation / special characters
  • Download as PDF. Print on white paper.
  • Write a small pencil note on each box: which mark goes here? This is your mark map.
Why punctuation?

> directs · { } frames · ! emphasises · / divides. The job is given. The shape is yours.

Fill each box boldly. Keep the mark inside the box.

✓ Works well

  • Bold brush marks
  • Thick pen gestures
  • Stamp prints
  • Drawn arrows, rectangles
  • Splattered ink

⚠ Test first

  • Light pencil
  • Pale ink
  • Very fine crosshatching
  • Photo textures
  • Scan at 300 DPI or more (or Adobe Scan / Microsoft Lens)
  • Save as JPEG
  • Straight, no shadows

Task 1
📤 Upload & Install Your Mark Font

Turn your scan into a font.
Then type your marks in Photoshop.

  • Log in to calligraphr.com ↗
  • Go to My Fonts → Upload Template
  • Choose your JPEG

Calligraphr now cleans up your marks automatically. In most cases you do not need to edit them.

Just check:

  • Each mark is found in the right box
  • No mark is cut off at the edges
  • The set looks consistent
Good to know

The rough parts of your marks stay. This makes them look hand-made.

  • Name: your name + theme, e.g. Sam_Industrial_Marks
  • Click Build Font
  • Check the preview
  • Download the .ttf or .otf file
  • Mac: double-click → Install Font
  • Windows: right-click → Install
⚠️ Important

Close Photoshop. Open it again. Now you can see your font.

  • Choose the Type Tool (T)
  • Find your font by name
  • Type the punctuation keys from your mark map
  • Try them small (12pt) and big (200pt)
  • Export: File › Export › Export As… → JPG → marks.jpg
🆘 Stuck? Try this
A mark is missing or cut off
Rescan at 300 DPI. Check the whole sheet is in the scan.
A mark did not appear
It may be too pale. Make it darker. Scan again.
My font is not in Photoshop
Close Photoshop completely. Open it again.
I cannot find my font
Click in the font box and type its name.
I forgot which key is which mark
Check your mark map.

Layout ideas

╱
Use a diagonal

Energy. Guides the eye across the page.

⬌
Connect

Arrows link your photos to artist references.

◻
Frame to analyse

A box says "this part matters".

≡
Text as a mark

Rotate it. Put it at an angle.

●
One accent colour

Use it for one job only.

░
Leave space

Empty space makes marks look deliberate.

Type on a path · click to open

  • Choose the Pen Tool (P) or Ellipse Tool (U)
  • In the top bar, set the mode to Path — not Shape
  • Draw a curve, a circle, or trace round a figure
  • Choose the Type Tool (T)
  • Move over the path — the cursor changes to a wavy line
  • Click on the path. Type.
  • Choose the Path Selection Tool (A)
  • Drag the text along the path
  • Drag across the line to flip it inside the curve

View › Show › Target Path — or click somewhere else. The line does not export.

References and knowledge text

📚 References
  • Artist + title + year, small, next to the image
  • Website: artist + website name
  • Book or archive: author or institution + publication
  • Use your accent colour — like Micky

❌ Just a label

"This is a photo of a cracked wall."

✓ Knowledge text

"The cracked surface connects to my research into urban decay — how buildings record time and use."

Explain: What do you see? Why does it matter? Which artist or idea does it connect to?

  • Keep layers: File › Save As… → PSD
  • Export: File › Export › Export As… → JPG → layout.jpg
🆘 Stuck? Try this
My text does not go on the path
Check the Pen Tool mode is Path, not Shape.
The text is upside down
Use the Path Selection Tool. Drag the text across the line.
I cannot see all my text
The path is too short. Make the text smaller, or draw a longer path.
My page is too busy
Delete some marks. Leave space.
